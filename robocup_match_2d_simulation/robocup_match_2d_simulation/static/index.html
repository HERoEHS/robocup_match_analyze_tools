Guide

아군, 상대, 공을 클릭해서 선택하고 키보드로 조종할 수 있습니다.

외부 Game Controller가 active 되면 READY/SET에서는 set point로 정렬되고, PLAYING에서는 역할 기준으로 움직입니다.

기본 설정에서는 외부 GC가 active 되기 전까지 자동 움직임이 잠겨 있습니다.

로봇끼리는 실제 로봇 크기만큼 완전히 겹치지 않게 분리되며, 지나치게 밀착하면 확률적으로 넘어질 수 있습니다.

원본 sender 파이프라인이 필요하면 이 시뮬레이터가 legacy topic도 같이 발행합니다.

외부 UDP sender와 함께 돌릴 때는 내장 UDP와 중복되지 않게 `publish_udp:=false`를 권장합니다.
